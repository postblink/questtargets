# Quest Targets 1.7.0

- RareScanner integration on Forever uses a secure minimap overlay and an independent radar pulse. The bar button searches marked world-map rares or the current area catalogue. Dungeon lookup combines native floor maps with the installed RareScanner catalogue’s dungeon IDs. Both native hotkey slots invoke the same secure search. Combat disables the action while the button stays visible.
- The targeting bar uses the modern compass with saved positions and scales. Layout, spacing, border and dividers are configured in the targeting-bar section, with guarded layout updates around combat.
- The patch notes window reads six localized changelogs and remembers the version seen per account. The latest entries are grouped by feature. Package validation checks the translated structures and generated Lua.
- The maintainer confirmed the preview worked in their client. Automated tests cover the update and language paths, native bindings, combat guards, bar layout and RareScanner search. The universal package is checked against the five declared interface IDs.
